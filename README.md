# ⚖️ BMI Calculator — Android Application

A modern and personalized Body Mass Index (BMI) calculator application built for Android using Kotlin and native XML layouts with Material Design components.

---

## ✨ Features

- **Personalized Interpretation:** Calculates BMI based on weight and height, taking into account the user's **gender** and **age** for more accurate recommendations.
- **Interactive UI:** Dynamic gender selector with visual highlighting (`orange_primary` / `orange_dark`).
- **Age Selection:** Dropdown `Spinner` allowing quick age selection (1–100 years).
- **Validation & Error Handling:** Prevents calculation with empty input fields via `Toast` alerts.
- **Formatted Results:** Displays calculated BMI up to 2 decimal places alongside health category descriptions (Underweight, Normal, Overweight, Obesity).

---

## 🛠️ Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Framework:** Android XML Views (`ScrollView`, `LinearLayout`, `EditText`, `Spinner`, `Button`)
